# 現代化單一園區靈骨塔位管理資料庫系統 (專案內容 A14)

本專案是一套針對現代化靈骨塔業則的營運痛點所開發的**關聯式資料庫管理系統**。傳統作業多依賴紙本或分散的試算表，容易發生重複劃位、祭拜時段與車位衝突等問題。本系統透過精準的資料庫綱要與關聯設計，核心劃分為「空間管理」與「時間排程」兩大模組，並創新導入「線上數位追思與虛擬參拜」功能，打造兼具營運效率與情感溫度的現代化管理平台。

---

## 📌 系統核心目標

1. **空間管理 (Slot Management)**：確保塔位狀態與關聯資料（購買會員、進駐先人）的一致性，徹底防堵重複劃位。
2. **時間排程 (Reservation System)**：自動協調實體祭拜時段與排他性車位配置，避免人流與車流衝突。
3. **數位化轉型 (Digitalization)**：提供線上追思留言與虛擬祭品功能，打破實體距離限制。
4. **規範化架構**：資料庫 Schema 完全符合 **3NF (第三正規化)**，確保無資料冗餘與更新異常。

---

## 👥 系統使用者與功能需求

系統依據權限與角色（`role`）劃分為三大類使用者：

### 1. 訪客 (Visitor) / 未登入用戶
* **空塔位查詢**：可依據樓層、預算區間動態篩選園區內的空置塔位。
* **瀏覽公告**：查看園區最新的最新動態、祭祀規範與活動通知。
* **註冊帳號**：填寫基本資料、身分證字號申請成為系統會員。

### 2. 會員 (Member)
* **名下塔位與親友查詢**：動態載入自身認購的塔位資訊，以及進駐先人的系統代碼與姓名（多表聯合關聯查詢 `SLOT JOIN DECEASED`）。
* **預約實體祭拜**：線上排定祭拜日期、時段與隨行人數，系統會自動分派排他性車位。
* **線上追思留言**：選定先人並配對虛擬祭品（如鮮花、蠟燭、水果），送出思念寄語。
* **管理費帳單查詢**：查看歷年應繳管理費總額與繳費狀態，支援線上模擬沖銷作業。

### 3. 管理員 (Admin)
* **營運儀表板數據**：即時統計總塔位數、現存空置數、今日預約人流、未清償帳單數。
* **塔位狀態異動管理**：可變更特定塔位的進駐狀態（空置/已售）。
* **發佈園區公告**：新增、編輯並發佈全新的園區公告。
* **審查預約總表**：透過多表關聯查詢，一覽所有會員的預約紀錄、排定時間、配對車位與當前狀態。
